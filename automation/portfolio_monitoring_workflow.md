# Portfolio Monitoring Workflow V2.0

## Flow
1. Load portfolio and watchlist records.
2. Identify positions due for review.
3. Collect new company, financial, market and macro evidence.
4. Compare new evidence with the previous thesis.
5. Run V1.2 scoring, V1.3 AI moat, V1.4 valuation and V1.5 decision modules.
6. Apply portfolio concentration and risk rules.
7. Classify GREEN / YELLOW / RED.
8. Generate a portfolio review report.
9. Record the decision and evidence trail.
10. Escalate only material changes.

## Safety
No live financial data is fabricated. No automatic trade execution is included in V2.0.
