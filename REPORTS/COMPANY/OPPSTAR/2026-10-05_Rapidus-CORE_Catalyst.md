# Oppstar (0275) — 2026-10-05 新催化剂：加入 Rapidus CORE

## Catalyst
2026-10-05，Rapidus Corporation 正式宣布建立 **Rapidus Collaborative Open Rapid Ecosystem (CORE)**，并公布首批 17 家 Design Solution Associates；**Oppstar Technology Sdn Bhd** 是其中之一。Rapidus 定义该群组的作用，是连接客户与 Rapidus 的先进 2nm 代工平台，为客户提供从早期设计到制造衔接所需的设计资源与专业能力。

## 为什么重要
1. **进入全球先进 2nm 生态链**
   - Oppstar 被列入 Rapidus CORE 首批 Design Solution Associates。
   - Rapidus 的 CORE 目标覆盖先进半导体开发与量产，并计划未来由 design 扩展到 EDA、IP 等类别。
2. **与 Oppstar 现有能力高度匹配**
   - Oppstar 本身具备 advanced-node IC design、physical design/layout、custom IP、turnkey ASIC/SoC 等能力。
   - 因此该合作不是完全跨界，而是把已有设计能力接到 Rapidus 的 2nm manufacturing platform。
3. **国际化价值提升**
   - Rapidus CORE 是全球生态框架，成员同时包括 Cadence、Synopsys、Toshiba Information Systems、Wipro、HCLTech、SkyeChip 等企业/机构。
   - 对 Oppstar 而言，战略意义高于普通单一客户新闻：有机会增加与国际客户、EDA、IP、制造生态的连接。

## 但必须严格区分
**目前公开资料没有证明：**
- 已取得具体金额的订单；
- 已取得多少 Revenue；
- 已锁定多少 2nm tape-out 项目；
- 已形成确定的盈利贡献；
- 已签订长期合约金额。

所以现阶段应分类为：

**Strategic Catalyst / Ecosystem Catalyst**
而不是：
**Confirmed Earnings Catalyst**

## 对投机作战手册的影响

原先：
- Catalyst：AI/HPC、order book、turnkey design、AI accelerator/NPU 等。

现在增加：
- **Rapidus CORE / 2nm ecosystem**
- **International advanced-node design ecosystem**
- **Potential customer-to-manufacturing pipeline**

Catalyst 评级：**由正面升级为强正面，但 earnings conversion 仍待验证。**

## 价格交易意义

截至 2026-10-05，市场资料显示 OPPSTAR 约 RM0.705，日内高 RM0.715、低 RM0.695；成交约 4.42m 股。10 月 2 日则上涨 5.26% 至 RM0.70、成交 8.29m 股。citeturn0search3

因此新催化剂出现时，股价尚未出现明显失控式拉升，短线仍应观察：

- RM0.715 附近：当日即时压力
- RM0.73–0.755：原先定义的主要突破区
- 若放量突破该区域：催化剂开始从“新闻”转化为“价格确认”
- 若突破失败：不能因为 Rapidus 故事而忽略技术结构

## 结论

**这是今天 OPPSTAR 一个真正值得升级评级的新催化剂。**

核心逻辑不是“加入一个合作名单所以一定赚钱”，而是：

> Oppstar 的现有 advanced-node design / IP 能力  
> → 接入 Rapidus 的 2nm foundry ecosystem  
> → 获得潜在国际客户与先进制程项目入口  
> → 若后续转化为 design wins / tape-outs / revenue，才成为真正的 earnings catalyst。

因此当前判断：

**Catalyst：🟢 强**
**Earnings conversion：🟡 待验证**
**Trading setup：🟡 等 RM0.73–0.755 突破确认**
**整体：WATCH → HIGH-PRIORITY WATCH**
