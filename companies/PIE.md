# P.I.E. Industrial Berhad (PIE, 7095) — 3QFY2026 财报归档

- **报告期间：** 截至 2026 年 9 月 30 日的第三季度及九个月
- **资料性质：** 未经审计中期财务报告
- **来源：** 用户提供的《PIB Interim Financial Report Q326.PDF》（25页）
- **报告日期口径：** 本记录只依据该份财报；未纳入股价、后续公告或外部行业资料。
- **金额单位：** 除每股数据外，均为 RM million（百万令吉）。

## 一、核心结论

PIE 在 3QFY2026 明显恢复：单季营收同比增长 4%、税前盈利同比增长 113%，管理层称主要来自 EMS 产能利用率提升、成本控制，以及 EMS 和 wire harness 订单回升。但累计九个月仍处于显著下滑：营收同比下降 24%，税前盈利下降 58%，股东应占盈利下降 65%。

关键投资主线是：**营运复苏是否能够延续，以及管理层提到的 AI Server 相关产品能否转化为可持续、具合理利润率的收入。** 报告称相关产品计划自 4Q2026 起逐步量产；这是公司前瞻陈述，不等于已确认订单金额或利润贡献。

## 三、业务分部与收入结构

## 四、环比改善与管理层展望

相较 2QFY2026：
- 营收从 RM180.132m 增至 RM212.482m，环比 +18%；
- 税前盈利从 RM5.809m 增至 RM12.655m，环比 +118%；
- 期间净利从 RM3.398m 增至 RM10.731m，环比 +216%。
- 公司解释增长主要来自 EMS 与 wire harness 需求改善。

管理层在报告中表示：
1. 公司在 2026 年第一季度受关税等外部因素影响而录得亏损，之后第二、第三季度恢复盈利。
2. 预期第四季度收入继续增长，并预计复苏动能延续。
3. 自 4Q2026 起，数项 AI Server 相关产品将逐步开始量产。
4. 2027 年及以后将加强 Switch 与 AI Server 相关业务；未来一至三年会评估 AI Key Components 与 Robotics 等新领域。

**投资解读：** AI Server 是潜在增长催化剂，但本份报告没有披露相关产品的订单金额、客户名称、营收占比或毛利率。因此目前只能列为待验证的成长机会，不应直接将其等同于确定的盈利爆发。

- 九个月已支付股息合计 RM7.681m；报告列示 2026 年特别中期股息 1.1 sen/股及中期股息 0.9 sen/股。
- 九个月购置物业、厂房及设备现金支出 RM20.583m。

## 七、风险清单

1. **EMS 复苏不确定：** 九个月 EMS 税前亏损 RM11.099m，需确认订单回流、产能利用率及利润率能否持续改善。
2. **现金流质量：** 九个月经营现金流仅 RM1.936m；库存与应收款增长需持续监控。
3. **AI Server 商业化风险：** 4Q2026 起逐步量产属于管理层展望；订单规模、客户集中度及产品利润率尚未在本报告量化。
4. **关税与贸易政策风险：** 公司称关税等外部因素影响第一季度表现。
5. **泰国业务盈利能力：** Wire Harness 九个月税前亏损 RM2.675m，较上年同期亏损扩大。
6. **外汇风险：** 九个月净外汇损失 RM2.582m；货币换算差额亦影响权益。
7. **历史税务争议：** 需追踪诉讼/上诉的最新进展及潜在现金影响。

## 八、投资研究框架初步评估

- **经营趋势：** 短期改善信号明确，但九个月累计业绩仍显著落后。
- **盈利质量：** 需要谨慎；单季利润恢复尚未转化为强劲累计经营现金流。
- **资产负债：** 权益基础仍大于负债，短期借款下降；但营运资金占用与应付款增加值得关注。
- **AI 成长主题：** 存在管理层明确提出的 AI Server 与 Switch 业务发展方向，但需以实际量产、订单披露和毛利贡献验证。
- **估值与合理买入价：** 本份财报没有股价、完整预测或订单利润资料，故暂不计算目标价、三情景估值或安全边际；须结合最新股价、后续季度数据与盈利预测另行评估。
- **暂定跟踪状态：** 观察名单 / 复苏验证阶段，而非仅凭 AI 主题直接判定买入。

## 九、后续季度跟踪指标

1. 4QFY2026 AI Server 产品是否如期量产，以及相关收入/订单是否有可量化披露。
2. EMS 季度收入是否恢复同比增长，并由亏损转为稳定盈利。
3. 毛利率能否从 3Q 的 7.31% 维持或改善。
4. 经营现金流、应收款及存货周转是否改善。
5. 泰国 Wire Harness 是否缩小亏损。
6. 关税及历史海关税务争议是否出现实质进展。
