# Source Capture Procedure V1.8

## Purpose
Capture an auditable original source before extracting data. Follow the V1.7 Evidence Engine, including data/evidence_schema.md, data/evidence_quality_rules.md and research/evidence/evidence_collection.md.

## Capture record
For each document, announcement, dataset or page record:
- Source capture ID and linked evidence/ingestion record IDs.
- Company name, Bursa ticker/security class or N/A for general macro/industry data.
- Exact source title, source organization/issuer, source type and source tier.
- Source URL, Bursa announcement/document identifier, file name or dataset/series reference.
- Publication date, event/observation date, reporting period and extraction/capture date.
- Document language, version, filing/audit/review status and original-versus-corrected/restated status.
- Page, section, table, note, slide or announcement paragraph for each extracted claim.
- Source quality and evidence strength as defined separately in V1.7.
- Capture method, collector/reviewer, access limitation and integrity reference if available.
- Linked superseding, conflicting and corroborating source IDs.

## Procedure
1. Verify source identity and origin; prefer official Bursa or issuer source.
2. Save or cite the original source reference where permitted; do not store credentials or bypass access controls.
3. Record metadata before extracting figures or claims.
4. Preserve source-reported wording/number/unit and context; extract only required data.
5. Assign stable source and evidence IDs; link each extracted value to its exact location.
6. If document cannot be retrieved or locator cannot be confirmed, label REQUIRES_VERIFICATION; do not imply a complete capture.
7. Preserve the old capture when a newer document/correction appears; create a linked capture record.

## Citation and privacy controls
Citations must be specific enough for a reviewer to reproduce the lookup. If a page has no pagination, record section/table/announcement ID or paragraph heading. Redact personal information not necessary for the research claim; do not publish restricted documents.
