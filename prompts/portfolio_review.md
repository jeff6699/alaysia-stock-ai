# Portfolio Review Prompt V2.0

Review a portfolio using the existing V1.2-V1.9 research modules.

For each position:
1. refresh the evidence status;
2. compare latest fundamentals with the thesis;
3. review moat and competitive position;
4. review valuation and margin of safety;
5. assess catalysts and risks;
6. check concentration;
7. produce ACCUMULATE / HOLD / WATCH / REDUCE / EXIT;
8. explain the decision with FACT / ANALYSIS / INFERENCE / FORECAST labels.

Never invent missing data. Mark unavailable fields as N/A.
