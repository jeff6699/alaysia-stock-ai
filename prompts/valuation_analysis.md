# Prompt: Multi-Method Valuation Analysis

## Goal
Estimate fair value range for a Bursa Malaysia company using suitable methods. Valuation is an estimate, not a precise prediction or automatic buy/sell recommendation. Use provided or verified data only. Never fabricate financials, prices, peers, multiples, rates, assumptions or forecasts.

## Inputs

Missing inputs = N/A and explain the affected method/output. Do not infer price or financial values.

## Required labels
FACT = sourced history/market data with date, period, units and source.  
ANALYSIS = formulas, method selection, normalization, comparison and interpretation.  
ASSUMPTION = every analyst-selected growth, margin, tax, capex, D&A, working capital, FCF normalization, WACC/cost of equity, terminal growth, target multiple, peer adjustment, dividend, scenario, blend weight and required MOS; give basis/rationale.  
INFERENCE = qualified conclusion, uncertainty and alternatives.  
FORECAST = calculated outputs from explicit ASSUMPTIONS, never reported fact.

## Method selection and DCF
Explain Selected/Cross-check/N/A for DCF, P/E, EV/EBITDA, PEG, P/B, Dividend Yield/DDM, FCF Yield and SOTP. Do not force all methods; adapt to banks, insurers, REITs, developers, contractors, plantations, cyclicals and other sectors.
For DCF: FCFF = EBIT×(1−tax)+D&A−capex−change in operating NWC; WACC discounts FCFF; terminal value = final FCFF×(1+g)/(WACC−g), with WACC>g; bridge EV to equity and divide by diluted shares. WACC discounts FCFF, cost of equity discounts FCFE/dividends. Show revenue growth, margin, tax, capex, D&A, working capital, FCF, WACC, g, horizon and all ASSUMPTIONS.

## Scenarios
Create BEAR CASE, BASE CASE and BULL CASE showing revenue growth, margin, FCF, WACC, terminal growth, period and fair value. All inputs are ASSUMPTIONS and outputs FORECASTS. Normally Bear growth/margin/FCF lower, WACC higher, g lower, FV≤Base; Bull reverses. Explain supported exceptions and investigate broken value ordering.

## MOS
Current MOS = (Base FV − Current Price) / Base FV; upside/downside = (Base / Current) − 1. State Required MOS separately as an ASSUMPTION with rationale; show buy-below if calculable.

## Confidence and safeguards
High: ≥3 independent relevant methods converge within 15% with evidence-backed assumptions. Medium: ≥2 partly converge within 25%, uncertainty bounded. Low: methods diverge >25%, data weak/N/A or unstable. Explain the applied rule; correlated methods do not add confidence.
Separate FACT, ANALYSIS, ASSUMPTION, INFERENCE and FORECAST. Do not use PEG for unsupported growth, terminal growth ≥ WACC, or incompatible valuation units. State this is informational decision support, not advice or a buy/sell recommendation.
