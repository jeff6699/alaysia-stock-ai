# Scenario Valuation — Bear / Base / Bull

## Evidence discipline
FACT = reported history, dated price, peer observations and sources. ANALYSIS = method, normalization, driver links and reconciliation. ASSUMPTION = every analyst-selected growth, margin, tax, capex, D&A, working capital, WACC, terminal growth, multiple, dividend, scenario and method weight. INFERENCE = qualified view and uncertainty. FORECAST = outputs from explicit assumptions. Missing data = N/A with impact stated.

## Build three cases
State base year, period, currency/units, diluted shares, price date and applicable methods. Use evidence such as filings, company history, capacity, order book, pricing, competition, management statements and sector outlook. Management guidance is a FACT about what management said, not a guaranteed result; modeled use is an ASSUMPTION.
Explicitly show revenue growth, operating margin, FCF type/value, WACC, terminal growth, forecast period and fair value for every case. Also show tax, capex, D&A and NWC assumptions. All future inputs are ASSUMPTIONS; outputs are FORECASTS.

## Ordering checks
Normally revenue growth, sustainable margin and FCF: Bear ≤ Base ≤ Bull; WACC: Bear ≥ Base ≥ Bull; terminal growth: Bear ≤ Base ≤ Bull and every g < WACC; fair value: Bear ≤ Base ≤ Bull.
These are coherence checks, not immutable laws. Explain an evidence-supported exception (e.g. high growth requires capex lowering near-term FCF). Investigate broken fair-value order; do not label unsupported optimism BULL.

Bear FV = Bear equity value / diluted shares. Base and Bull calculated likewise.
Current share price is dated FACT; otherwise N/A.
Upside/downside to Base = (Base FV / Current Price) − 1.
Current MOS = (Base FV − Current Price) / Base FV.
If any required value/denominator is N/A or invalid, output N/A and explain.

## Method consistency and sensitivity
Use same method definitions across cases. Method output may become N/A if its required input becomes invalid (e.g. negative EPS for P/E). Show WACC/terminal-growth and key operating sensitivities. State terminal value as share of DCF EV. Do not assign scenario probabilities unless supported and labeled ASSUMPTION.

## Conclusion
FACT: starting inputs, price date and sources.
ANALYSIS: case differences, formulas and consistency.
ASSUMPTION: all drivers, rates, multiples and weights.
INFERENCE: risk/reward, uncertainty, falsifiers and alternatives.
FORECAST: Bear/Base/Bull outputs and sensitivity.
