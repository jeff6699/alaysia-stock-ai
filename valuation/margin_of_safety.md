# Margin of Safety Framework

## Definition
Margin of Safety (MOS) compares estimated intrinsic value with market price. It allows for model error and uncertainty; it does not make value certain or prevent losses.
- Current MOS % = (Base Fair Value − Current Share Price) / Base Fair Value × 100.
- Upside/downside to Base % = (Base Fair Value / Current Share Price − 1) × 100.
- MOS buy-below price = Base Fair Value × (1 − Required MOS %).

Show dated current price and base value methods. If price/value is N/A, Base Fair Value ≤0 or denominator invalid, MOS is N/A with explanation. Negative MOS means price is above modeled Base value. Current MOS is distinct from a required MOS threshold.

## Required MOS is an ASSUMPTION
Select and justify required MOS based on confidence, volatility, leverage, cyclicality, disclosure quality, forecast visibility and downside asymmetry. Higher uncertainty normally calls for a larger cushion; there is no universal percentage. Do not reverse-engineer it to force an undervalued conclusion. State currency/share basis. The buy-below value is a research screen, not a trade instruction.

## Apply to a range
Use Base Fair Value for headline current MOS. Show Bear/Base/Bull values separately; optional MOS to Bear/Bull is sensitivity. Disclose blend weights and confidence. Avoid double-counting risk already in modeled cash flows/discount rates and again in MOS.

## Confidence
High confidence may support a smaller cushion only when evidence converges and uncertainty is modest. Medium confidence warrants a wider cushion. Low confidence can make MOS too unreliable to guide interpretation. Chosen MOS is still an ASSUMPTION.
Valuation is an estimate, not a precise prediction or automatic buy/sell decision.
